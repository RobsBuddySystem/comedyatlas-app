COMEDY ATLAS is a working directory of upcoming stand-up shows, comics, and bookers in English-speaking comedy scenes worldwide. The people using it are industry, not casual browsers: comics checking stage-time opportunities, bookers filling lineups, and venues managing their own listings — today concentrated in a handful of active markets by listing volume (London, Montreal, Edinburgh, Barcelona, Washington, Madrid, Tacoma and Portland), with lighter coverage growing across the other cities that already have at least one live listing. The quality proof

The approval-record and high-confidence figures are in the box above, because they are generated at publish time from the production database — the same run that writes the counts. We used to print a fixed "78.4%" here alongside the sentence "this number moves as the pipeline runs", which was self-contradictory: the number was typed in and moved only when someone retyped it. It is computed now. It is also a figure that genuinely swings with ordinary ingest activity, so treat any single reading as a snapshot, not a guarantee.
